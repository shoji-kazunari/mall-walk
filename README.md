# mall-walk

ショッピングモールをいつでも味わえる。

広いおもちゃ売り場を歩いて、棚に並んだ商品を眺めるだけのウィンドウショッピング。
「狙って買う」ではなく「うろうろして見つける」楽しさを再現するのが目的。

## 遊び方

- **PC**：画面をクリックして入店。WASD・矢印キーで歩く（Shiftで早歩き）、マウスで見回す。
  近くの商品をクリックすると手に取って見られる
- **スマホ**：画面の左側をなぞると歩く、右側をなぞると見回す。近くの商品をタップすると手に取れる

品ぞろえは日付ごとに入れ替わる（同じ日なら同じ並び）。

## いまの状態（試作）

- 売り場はおもちゃ売り場1フロア（約92m×132m、天井10m、10売り場）
- 商品はすべて試作用の**架空のもの**。canvasで手続き的に描いている
- 本物の商品（楽天ウェブサービスの商品検索API）への差し替えは次の段階

## 作り

ビルド工程なしの静的サイト。`index.html` をそのまま配信すれば動く（GitHub Pagesで公開できる）。
ローカルで試すときは `npx http-server .` などで配信して開く（ESモジュールのため `file://` では動かない）。

| ファイル | 中身 |
|---|---|
| `js/main.js` | 描画ループ・移動と当たり判定・商品を手に取る・ミニマップ |
| `js/world.js` | 店内のレイアウト（床・柱・棚・看板・島陳列） |
| `js/catalog.js` | 売り場の定義と架空の商品データ |
| `js/art.js` | 商品パッケージと看板をcanvasに描く |
| `js/controls.js` | キーボード・マウス・タッチ操作 |
| `vendor/three.module.min.js` | three.js r160（MITライセンス、`vendor/three.LICENSE`） |
